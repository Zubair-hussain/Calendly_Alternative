Book meetings with a clock, on your own terms.

ZH Booking is a free, open-source, self-hosted alternative to Calendly. It connects to your Google Calendar and runs on your own Vercel account.

Try booking View on GitHub

How a guest books

  1. Pick a dateAvailable weekdays are highlighted.
  2. Set the clockChoose an open hour, then the minutes.
  3. Add detailsEnter a name, email and optional notes.
  4. Get the inviteA calendar invitation with a Google Meet link arrives by email.

What happens behind the page

  1. Reads your calendarBusy times are removed from the clock.
  2. Checks againThe server re-checks the slot before booking.
  3. Blocks duplicatesEach slot has one event ID, so a second booking is rejected.
  4. Creates the meetingGoogle adds the event and Meet link and emails the guest.

Run your own

Fork the repository, create Google OAuth credentials, add them as Vercel environment variables, and deploy the _prod branch. The README has the details.
